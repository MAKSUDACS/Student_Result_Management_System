# Student Result & Performance Management System

## Project Overview
The Student Result & Performance Management System is a Python-based project designed to manage student information, calculate academic results, and generate class performance summaries.

## Features
- Add new students
- Search students by Student ID
- Display all student records
- Calculate total marks, average, and percentage
- Automatically assign grades
- Check Pass/Fail status
- Find the highest-performing student
- Find the lowest-performing student
- Generate class performance summaries
- Save and load student records using CSV files

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- CSV Module
- File Handling

## How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the VS Code Terminal.
4. Run the following command:

```bash
python main.py
```
